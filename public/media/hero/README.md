# Live lesson preview

Recorded from https://app.rsquaredacademy.com/dplyr/filter-predict on
14 November 2026 using Playwright at device scale 2 and 130% page zoom (CSS `zoom`).
The real diagram's Play control advances from the six sales rows to the two
Large sales. Back restores the first step before the eight-second loop ends.
No exercise was answered, no solution opened and no code submitted.

Desktop and phone recordings use the app's responsive layouts, in light and
dark. Each frame is cropped to the diagram in the lesson pane. Its changing
height is padded with the app's actual page background to keep a fixed box;
no lesson text, table values or interface elements are replaced. The top bar
and subsequent lesson/example code are outside the crop. Streak and XP
controls were present in the live top bar, but are not included in any asset.

Each variant has a silent H.264/yuv420p MP4 with fast-start metadata, a VP9
WebM, and a WebP poster of its first frame. `capture.json` records dimensions,
capture settings, text sizes and byte counts. The complete four-variant set,
including posters, is below 1.5 MB; a browser downloads one theme/layout and
one supported video format.

Run `node scripts/record-hero-loop.mjs` to reproduce. It needs the repository's
existing Playwright and Sharp, plus ffmpeg on PATH. Raw screenshots and
timelines are written to the system temporary directory, never committed.
Set `HERO_WORK`, `HERO_OUTPUT` or `FFMPEG` to override those locations.
